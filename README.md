# E-Commerce ERP CRM Platform


## Overview

Enterprise commerce platform consisting of:

- Online Store
- ERP System
- CRM System
- Android Mobile Application
- Marketplace Integration
- WhatsApp Integration
- KPI Dashboard

Frontend:

- TypeScript
- Tailwind CSS


Backend:
- Python FastAPI


Database:

Mobile:

Infrastructure:
